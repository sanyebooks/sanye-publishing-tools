## 6. 首批建议测试的用户买点场景

默认输出 6—8 个，按策略优先级排列。每个场景使用以下格式：

### 场景 N：可识别的场景名称

- **优先级**：重点测试 / 组合测试 / 候补
- **一句话测试假设**：如果向____情境中的____呈现____，他们会因为____而产生点击或购买兴趣。
- **用户处境**：具体到事件、动作和心理。
- **购买触发**：什么让需求从潜在变为当下。
- **近期时间机会**：节点、绝对日期范围和为什么现在更值得测试；无近期放大时标为常青。
- **准备期 / 发布期 / 失效期**：节点型场景必须填写。
- **依据类型**：日历事实 / 趋势假设 / 已验证趋势。
- **用户真正想获得的进展**：不是产品属性。
- **本书独特回应**：说明机制，而非空泛收益。
- **原文证据**：内容摘要＋页码/位置＋证据等级。
- **可测试点击入口**：给方向，不批量写成品标题。
- **建议画面场景**：优先真实阅读/使用场景，说明书封是否需要出现。
- **主要风险**：可能误导、过窄、证据不足、剧透或转化弱等。
- **评分**：即时性__/5；可识别性__/5；独特性__/5；可视化__/5；证据__/5；基础价值__/25；时机__/5；首测优先级__/30。
