# 输入与证据规范

## 可用输入

- 选题名称、内容简介、作者介绍
- 目录、样章、完整书稿、策划案
- 目标读者描述、访谈记录、评论语料
- 竞品清单、销售/投放数据、渠道反馈
- 产品形态、定价、装帧、出版节奏
- 公司渠道、达人、私域、机构和品牌资源

## 最小事实卡

至少尝试确认：

1. 这本书写给谁？
2. 读者在哪个具体场景下需要它？
3. 它解决什么问题或提供什么明确收获？
4. 为什么是这本书，而不是免费内容或同类竞品？
5. 为什么适合做成纸质书？
6. 作者凭什么写、凭什么被相信、能否参与传播？
7. 出版方现在有哪些触达资源和战略目标？

## 证据等级

| 等级 | 定义 | 示例 |
|---|---|---|
| A 直接证据 | 直接来自对象或真实行为的数据 | 书稿原文、读者访谈、成交、预售、投放转化、已确认合作 |
| B 间接证据 | 能支持判断但不是本项目直接验证 | 可靠竞品数据、作者历史项目、行业报告、同类案例 |
| C 合理推断 | 从现有材料推导，尚未验证 | 根据目录推断使用场景、根据评论推断潜在人群 |
| D 未知 | 缺少支撑材料 | 没有读者研究、没有竞品数据、资源未确认 |

## 事实纪律

- 用“材料显示”描述事实，用“推测/可能”描述推断，用“待验证”描述未知。
- 精确销量、排名、搜索量、转化率、平台趋势必须附来源和时间。
- 作者粉丝数不自动等于图书购买力；需要互动质量、受众重合和历史转化证据。
- 竞品畅销不自动证明本书能卖；还要解释差异化、切入时机和渠道能力。
- 读者说“喜欢”不等于愿意购买；优先寻找行动、付费或替代成本证据。

## 追问原则

按“答案最可能改变结论”的顺序追问，一次最多 7 个。优先追问：

1. 五个必须项中的未知信息。
2. 可能形成 `<2` 致命短板的信息。
3. 能区分 2 分与 3 分、3 分与 4 分的证据。
4. 能低成本验证的关键假设。

若用户暂时无法补充，继续生成“暂定评估”，清楚标注置信度和待验证项。

## 用户必须亲自选择的项目

AI完成五个必须项初评后，单独向用户询问：

1. 公司资源匹配度：高 / 中 / 低
2. 长期/战略价值：高 / 中 / 低

AI可以先摘要相关资料，但不得替用户判断、预填或默认选择。收到两项选择后，才计算最终总分并输出正式评估报告。
