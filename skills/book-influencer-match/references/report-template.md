# 简短报告模板

报告优先控制在用户能快速阅读和转发的长度。证据截图紧跟对应结合点或作为有编号的附件。

```markdown
# [达人名称] ×《[书名]》推广结合点分析

分析平台：[平台；仅基于当前平台或多平台综合]
匹配结论：[值得重点联系 / 可以尝试 / 暂不建议匹配]
一句话判断：[最重要的原因与最佳切入方向]

## 实际调研范围
- 主页：[原链接]
- 调研日期：[日期]
- 扫描：[数量、时间跨度、全量或分层抽样]
- 候选作品：[数量] 条；深读：[数量] 条；查看评论区：[数量] 条
- 选证标准：[近期性、流量表现、图书相关性；主证据时间范围]
- 图书资料：[材料名称与证据强度]
- 限制：[访问或资料限制]

## 结合点一：[能直接成为选题的具体观点]
**建议等级：** [核心结合点 / 备选结合点 / 潜在线索]

**为什么适合这个达人：** [达人长期内容、近期兴趣或粉丝需求]

**达人侧证据：**
- [近期主证据/补充证据/历史风格参考] [内容标题/摘要]｜[日期]｜[可见互动]｜[可点击的完整原链接]
- [关键表达或评论需求概括]
- [截图编号或附件链接]

**图书侧证据：**
- [章节/页码/材料名称]
- [具体观点、案例或方法]

**建议内容选题：** [符合达人原有表达方式的具体选题]

**建议的钩子开头：**
1. [直接回应粉丝痛点或具体场景的开头]
2. [延续达人原有观点或表达习惯的开头]
3. [可选：以冲突、反常识或问题切入，但必须由书中内容承接]

**联系达人时可以这样说：**
> [简短沟通话术，不承诺效果]

**风险或待确认：** [证据弱点、重复选题风险或待补材料]

## 其他结合点
[按相同结构最多再写两个；没有就省略。]

## 不建议采用的牵强角度
- [看似相关但证据不足的方向及原因]

## 最终建议
[是否联系、优先方向和低风险验证动作]
```

结论为“暂不建议匹配”时，保留调研范围，列出未成立的候选方向、缺失证据和是否值得补充其他平台分析；不要生成联系话术。
