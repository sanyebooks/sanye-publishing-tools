# 正文结构选择

先判断场景的主购买动机，再选择结构。一个场景只用一个主结构；必要时可以借用另一结构的局部，但不要拼成杂糅长文。

## 共同底层链条

所有结构都要完成：

`具体处境 → 用户卡点 → 问题重构 → 本书独特回应 → 具体内容证明 → 购买理由 → 自然收尾`

用户首先需要认出“这与我有关”，之后才会关心书有什么。商品应在完成处境和转折后自然进入，不要先罗列作者、销量、装帧和推荐语。

## 1. 强痛点结构

适用：拖延、反复失败、失控、内耗、完美主义等正在发生的问题。

顺序：

1. 还原一个具体失败现场；
2. 写出用户对自己的负面判断；
3. 推翻错误归因；
4. 引入书中的解决机制；
5. 给出一个可理解、可执行的动作；
6. 说明拥有这本书的价值。

重点：让用户意识到“不是我不行，可能是方法或体系有问题”。不要只提供情绪安慰。

表层形态：短场景开篇，段落短促；用 `❌` 标记旧循环、`💡` 标记问题重构、`✅` 给出下一步。避免长篇第二人称履历。

## 2. 知道但做不到结构

适用：读过原版、听过课程、收藏大量方法，但没有真正行动。

顺序：

1. 呈现知道很多却没有变化的反差；
2. 指出理解与行动之间的鸿沟；
3. 说明这本书如何把理论变成练习或工具；
4. 展开一个具体页面、方法或流程；
5. 解释为何需要拥有并实际使用，而不只是看完一篇内容。

重点：比较不同产品承担的任务，不踩一捧一。

表层形态：使用“知道 / 做到”或“理解 / 执行”的简短对照，正文中段尽早出现产品差异；不要仍写成完整失败故事。

## 3. 工具使用结构

适用：评估表、练习页、清单、索引、追踪表、速查表等具体工具。

顺序：

1. 提出一个明确问题；
2. 写明书中哪种工具回应它；
3. 用自然语言演示使用步骤；
4. 说明填写或执行后能看清什么；
5. 将单个工具连接到完整购买理由。

重点：演示工具如何解决问题，不罗列“书里有很多表”。

表层形态：采用“一问 + 三步演示 + 一个结果”的教程节奏，可用 2—3 条短项目符号；不要用情绪故事占据大半正文。

## 4. 近期节点结构

适用：开学、返校、入职、搬家、年度复盘、新年计划及其他明确时间节点。

顺序：

1. 点出当前节点中的真实动作或决定；
2. 写出用户此时最容易犯的错误；
3. 解释为什么旧方法在新阶段可能失效；
4. 给出书中的当前行动；
5. 说明为什么现在使用比以后再说更有意义。

重点：节点必须改变用户任务或情绪，不能只在标题上贴节日标签。趋势假设不能伪装成搜索事实。

表层形态：用 `⏰` 点出节点，再给“现在先做的一件事”；根据当前日期选择未来、进行或复盘口径，避免虚构未来经历。

## 5. 反完美与重启结构

适用：断签、自责、一次失败后放弃、计划崩溃。

顺序：

1. 写出一次具体失误；
2. 还原失误后的自我对话；
3. 区分失误与彻底放弃；
4. 引入书中的重启机制；
5. 给出最低可行动版本；
6. 让用户重新获得掌控感。

重点：用具体方法托底，避免写成泛鸡汤。

表层形态：用“失误 → 下一步”的短链条，可用 `🔁` 呈现循环、`✅` 呈现重启动作；避免再次使用强痛点结构的长场景。

## 6. 身份愿望结构

适用：想成为阅读者、运动者、写作者或更有秩序的人。

顺序：

1. 写出用户想成为的样子；
2. 呈现当前行为与愿望的距离；
3. 解释身份与重复行动的关系；
4. 给出一次微小但具体的身份行动；
5. 说明书如何陪伴长期积累。

重点：用正向愿望驱动购买，不必每篇都放大焦虑。

表层形态：以愿望或身份选择开篇，用较平静、向前看的语气；不得硬塞失败、自责和羞耻。

## 7. 环境解决结构

适用：手机、零食、宿舍、书桌、家庭或工作环境造成的行为反复。

顺序：

1. 还原环境如何不断触发旧行为；
2. 说明仅靠意志力为何反复失败；
3. 用书中观点重新解释自控；
4. 给出一个环境调整动作；
5. 说明书中的系统方法如何支持继续调整。

重点：让商品成为改变条件的工具，不是继续要求用户“忍住”。

表层形态：使用“环境改造前 / 改造后”对照或 2—3 项行动清单；以物件和空间为主，减少心理独白。

## 8. 差异对比结构

适用：原版与实践版、普通打卡本与系统手册、同系列不同功能产品。

顺序：

1. 承认两者表面相似；
2. 说明各自解决的任务；
3. 用具体内容证明差异；
4. 指出什么处境下更需要当前产品；
5. 形成清晰而克制的购买判断。

重点：比较功能和使用任务，不贬低其他产品，不制造虚假优劣。

表层形态：使用两列式或交替短句对比“它解决什么 / 本书解决什么”，结尾给适用判断；不要再套失败场景开头。

## 批次差异要求

一批笔记中：

- 不要连续三篇使用相同的疑问句开头；
- 不要每篇都先写失败和焦虑；
- 不要每篇都用“不是你不自律”作为转折；
- 不要每篇都以“如果你也……”收尾；
- 即使两个场景使用同一结构，也要改变叙述视角、节奏和证据组织。
- 统计核心证据与工具的复用次数；同一工具支撑多篇时，必须明确不同购买动机，不能让多篇最终都落到同一个动作。
- 检查各篇的可见形态：叙事、对照、教程、清单、复盘、身份表达至少应有明显差异，不能只在批次核对中声明“结构不同”。
